01 / STATISTICAL MODEL BENCHMARK

local-model-eval

github.com/NathanLCR/local-model-eval →

Standalone Python eval harness measuring gemma4 E4B, qwen3.5 9B, and Bonsai 2 27B through the same llama-server build across tool calling (#1), cited PDF QA (#2), and PT-BR voice (#4).

  • Frozen context + 3 repeats/item: Re-uses real app prompts and frozen retrieval chunks so timings measure the model, not engine drift, with 10,000-resample item-cluster bootstrap 95% CIs.
  • CI overlap tie-breaker: Overlapping confidence intervals resolve to thinking-off, then smaller weights—awarding #2 PDF QA to gemma4-nothink (85% [74–95%]) over gemma4-think (89% [79–97%]).
  • Real bugs surfaced: Caught qwen3.5-9b-think running git push --force on trap t18, qwen3.5-9b-nothink omitting [chunk_id] tags on 98/102 #2 runs, and PDF accent splitting in Portuguese papers.

02 / COMPANION & MULTI-DEVICE PANELS

lupin-desk

github.com/NathanLCR/lupin-desk →

FastAPI voice-first desktop companion and multi-device panel system that turns spare phones, tablets, an Anbernic RG406H, and Kindles into live desk dashboards driven by one local Mac Brain.

  • One Brain, typed Actions: Devices connect over WebSocket and send registered Action IDs, never raw commands. Mac controls run through subprocess.run with an argv whitelist (never shell=True).
  • Per-provider Data Consent: Calendar, email, and file contents reach an LLM provider only when explicitly consented for that provider; E-ink Mode serves zero-JS HTML for Kindles.
  • Measured agent orchestration: Across 9 benchmarked issues in docs/agent-workflow-report.md, a single Sonnet agent used 133k tokens vs 572k for 1 Sonnet lead + 4 Haiku coders, with a third of the code churn (752 Python + 447 JS tests pass).

03 / GROUNDED ACADEMIC PDF RAG

article-rag

github.com/NathanLCR/article-rag →

Local-first academic paper QA system in a zero-build open-notebook interface (Caderno B2) that ties every cited sentence directly to highlighted bounding boxes on the rendered PDF page.

  • No LangChain, zero innerHTML: Custom FastAPI + ChromaDB + PyMuPDF pipeline paired with zero-build ES modules using text-node-only DOM rendering.
  • Citation localization & cleanup: Prunes trailing reference sections before indexing, flags broken PDF ligatures via suspect_ratio, filters distance above MAX_DISTANCE = 1.3, and overlays PyMuPDF coordinates onto 2x page renders.
  • Research trace transparency: Exposes sub-queries, retrieval rounds, neighbor-chunk expansions, and match quality directly next to the taped PDF page sheet (338 tests across 16 files, including 172 E2E checks).

04 / GOVERNED STUDY AGENT

atenas

github.com/NathanLCR/atenas →

Telegram-first local LLM study assistant backed by FastAPI, SQLite, a Click CLI/TUI, and a local observability dashboard, defaulting to local Ollama with strict allowlist protection.

  • Deterministic core, constrained tools: Code validates inputs and handles persistence while the LLM operates only through registered tools; every state mutation is logged.
  • Three-tier governance: Separates tool calls into auto (reversible local writes, audited), confirm-first (human approval for deletes or external egress), and forbidden.
  • Inspectable traces & backups: Ships with atenas doctor, trace inspection, TUI view, backup/restore commands, and a read-only dashboard over SQLite (690 tests across 59 files).

05 / SURGICAL OOXML DIFF

docdiff

github.com/NathanLCR/docdiff →

Offline .docx review interface that inspects LLM-suggested edits side-by-side and patches accepted changes straight into the original XML with lxml, making zero network calls.

  • Preserves tables, images & styles: Copies every archive member untouched except word/document.xml, modifying only target <w:t> text runs while preserving <w:rPr> formatting and atomic tokens ([[img:NN]], fields, breaks).
  • Prompt-paste & compare modes: Supports chunked copy-paste JSON prompts with SHA-256 block hashes as well as banded DP alignment against a second .docx (including 2→1 merges and 1→2 splits).
  • Safety flags & verification: Flags numeric edits, >40% length shifts, and low-confidence changes; verified across 104 pytest tests (6 suites) and React/Vite UI builds.

06 / MACOS ALLOWANCE MONITOR

claude-usage-monitor

github.com/NathanLCR/claude-usage-monitor →

Lightweight macOS menu-bar and edge-notch monitor (~3.9k LOC Python) reporting remaining account allowance and local token activity across Claude.ai, ChatGPT/Codex, and Antigravity/Gemini.

  • Allowance first, zero fake pricing: Leads with 5-hour and 7-day % left windows plus reset countdowns; never estimates fake API dollar spend.
  • Metadata-only local scanning: Parses byte-offset JSONL metadata from ~/.claude/projects/ and ~/.codex/sessions/ plus SQLite protobuf step counters—ignoring all message bodies and reasoning text.
  • Honest degradation & tests: Explicitly surfaces expired cookies or stale (>24h) Codex snapshots instead of zeroes; 29 unit tests pass on Python 3.14.
